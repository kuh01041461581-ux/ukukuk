# 서무 종합프로그램 (HTML 한 파일)

공무원 서무 업무용 브라우저 도구 8개(관내여비·관외여비·급식비·이미지 압축·얼굴 블러·도장 추출·수료증 취합·고지서 인식)를
**HTML 파일 하나**로 묶은 것. 모든 처리는 브라우저 안에서만 한다.

```
python3 seomu/build.py        # → seomu/dist/서무종합프로그램.html  (이 파일 하나만 배포)
```

## 구조
- `src/shell.html` — 바깥 틀(사이드바·상단 제목/설명·로딩·도움말·다크모드·단축키)
- `src/tools/*.html` — 도구 8개 원본 (각자 독립 HTML, `<!--SEOMU-COMMON-->` 자리에 공통 CSS/JS 가 들어감)
- `src/common/ui.css` — **공통 디자인**: 색·글꼴·버튼(주/보조/위험)·입력칸·표·카드·소개 상자
- `src/common/ui.js` — 공통 동작: 다크모드 신호, 라이브러리 지연 로드(`seomuLoad`), 파일 끌어놓기 보호, 단계 이동(`seomuStepNav`)
- `build.py` — 위를 합쳐 한 파일로 (도구는 base64 로 담겼다가 탭을 열 때 iframe 에 풀림)

## 설계 원칙
1. 제목·메뉴·설명은 셸이 한 번만. 도구 안의 중복 제목/브랜드/속 사이드바는 숨기거나 위쪽 탭·단계 막대로 바꾼다.
2. 색·글꼴·모서리는 `ui.css` 의 `--u-*` 토큰 하나. 도구별 변수는 각 도구 `<style id="seomu-tool">` 에서 토큰에 연결.
3. 버튼은 역할별 한 벌: 주 동작(파랑 채움, 오른쪽/아래) · 보조(테두리) · 위험(빨강 테두리).
4. **첫 화면을 막는 외부 요청 금지**: 라이브러리는 `defer`, 큰 것(pdf.js)은 쓸 때만 `seomuLoad('pdf')`,
   글꼴은 `media=print` 지연 로드. 같은 라이브러리는 같은 URL(캐시 공유).

## 관외여비가 느렸던 이유
`<head>` 에서 cdn.sheetjs.com·jsDelivr·cdnjs 스크립트 3개와 Pretendard CSS 를 **동기로** 받아 화면 그리기가 그 응답이 끝날 때까지 멈췄다
(다른 CDN 보다 느린 사이트가 끼면 수 초). → 모두 비동기/지연으로 바꾸고, xlsx·jszip 은 다른 도구와 같은 cdnjs 주소로 통일.
시험(CDN 응답을 3초로 지연): 첫 화면까지 3660ms → 126ms.
