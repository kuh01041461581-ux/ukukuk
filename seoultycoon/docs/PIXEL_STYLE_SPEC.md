# 익산타이쿤 새 건물 도트 제작 규격 (서울타이쿤2 원본 분석 기준)

새 건물은 이 규격으로 `tools/pixel_direct.py` 의 `Px` 도구로 **96폭 저해상도 캔버스에 직접 찍는다**. 큰 그림을 줄여서 만들지 않는다(뭉개짐·잡색의 원인).

## 1. 원본에서 측정한 사실 (b17 교회, b3 롯데 건물 등을 화소 단위로 덤프)

### 윤곽선
- **검은 윤곽선이 없다.** 면과 면의 경계는 *같은 색상의 한두 단계 어두운 톤*으로 구분한다. 건물 바깥 가장자리도 그 재질의 어두운 톤(지붕=진한 자주, 벽=진한 노랑 갈색)이다.
- 바닥 마름모 가장자리에는 밝은 연보라 테(`#b6b6ff`)와 주황 울타리/보도 띠가 있다.

### 색 사용
- 건물 하나에 **25~35색**. 재질마다 **4~6단계 색띠**(밝은 하이라이트 → 중간 → 어두운 면 → 그림자 → 가장 어두운 접지색).
- 색은 **저채도 흙빛이 아니라 맑은 원색 계열**: 풀 `#a2e601 #67db00 #6db601 #009200 #006d00 #004900`, 지붕 `#ff6d55 #ff9255 #db4955 #9a0d55 #6f1254`, 벽 `#ffffab #fedbab #feb500 #d59200`, 그림자 `#472257 #6d4955`.
- **하이라이트는 왼쪽 위, 그림자는 오른쪽 아래.** 왼쪽 면이 밝고 오른쪽 면이 어둡다. 오른쪽 면은 같은 색을 단순히 곱해 어둡게 하지 않고 *색상을 약간 보라/붉은 쪽으로 돌린다*(노란 벽 `#ffffab` → 오른쪽 `#d59200`/`#a26dab`).

### 질감은 디더(체크무늬)와 줄무늬로
- 지붕: **두 색 체크무늬 디더**(`#ff6d55`/`#ff9255` 번갈아) 한 줄씩 어긋나게. 경사 줄마다 어긋남이 이어진다.
- 벽: **2열 폭의 세로 줄무늬 두 톤 반복**(`#db93ac`/`#dab8ab` 두 열씩). 창 사이 벽면, 유리 커튼월 모두 이 방식이다. 단색 면에 점을 흩뿌리지 않는다.
- 면이 큰 곳은 *두 톤 체크 디더로 그라데이션*을 만들고, 면이 작은 곳은 단색으로 둔다.

### 창·문
- 창은 3~4색: 어두운 창틀 `#6f1254` + 밝은 유리 + 한 칸 하이라이트 + 안쪽 그림자. 문은 아치/박공 틀을 별색(`#b66d00` 주황 갈색)으로 두르고 안은 거의 검은 `#30303a`.
- 창 하나는 2~4화소 폭. 창 사이 벽 기둥 폭이 1~2화소.

### 나무 (b17 왼쪽 나무: 12×14화소, 색 18개)
- 모양은 **둥근 덩어리 한 개**가 아니라 **작은 둥근 잎덩이 여러 개가 겹친 덩어리**다. 외곽이 울퉁불퉁하다.
- 하이라이트 `#a2e601`·`#67db00` 는 *각 잎덩이의 왼쪽 위*에 2~4화소 점으로 여러 군데에 있다. 어두운 `#009200 #006d00 #004900` 는 *각 잎덩이 오른쪽 아래*와 덩어리 사이 틈이다.
- 줄기는 짧은 갈색 2열(`#b64900 #feb500 #936d01`) + 밑에 어두운 그림자. 땅에 붙는 그림자는 오른쪽으로 길게 번진다.
- 윤곽선 없음. 잎덩이 경계는 어두운 초록으로만 구분.

### 바닥·접지
- 건물 밑동에 가장 어두운 접지색 한 줄. 오른쪽 아래로 짧은 그림자(해당 바닥색의 한 단계 어두운 톤).
- 마당은 잔디 3~4톤 체크 디더, 길은 연한 베이지 + 점선 무늬.

## 2. 우리가 지금까지 틀린 것 (춘포역 1차 결과에서)
1. 벽: 가로 띠 5단계 그라데이션 + 점 → 원본은 *2열 세로 줄무늬*와 *체크 디더*. 단색에 가까워 밋밋하다.
2. 나무: 큰 원 하나 + 하이라이트 원 하나 → 원본은 잎덩이 여러 개와 3~6단계 초록.
3. 지붕 기와: 점을 한 칸씩 흩뿌림 → 원본은 줄 단위 체크 디더 두 톤.
4. 색 수 부족: 벽 3~4색 → 원본 건물은 벽만으로도 6~8색.

## 3. 새 건물 하나를 만드는 순서 (프롬프트)
```
역할: 서울타이쿤2 원본 건물처럼 96폭 아이소메트릭 도트를 코드(Px)로 직접 찍는다.
입력: 건물 사진(레퍼런스), 캔버스 높이/바닥 마름모 줄(strips.canvas(k)), 이 문서.
절차:
 1) 큰 덩어리 확정: 바닥(마당·보도) → 본체 → 지붕 → 입구/부속채 → 장식. 각 덩어리의 a,b,z 범위를 먼저 표로 적는다.
 2) 덩어리마다 재질 색띠(4~6색)를 정한다. 왼쪽 면은 밝은 쪽 3색, 오른쪽 면은 보라 쪽으로 돌린 어두운 3색.
 3) 면을 평평한 색으로 채운 뒤 *질감 함수*로만 디테일을 넣는다: checker(a,b,색1,색2), stripes(열폭2, 색1,색2), window(틀,유리,하이라이트), tree(잎덩이 6~8개).
 4) 검은 윤곽선을 쓰지 않는다. 경계는 면 색의 한 단계 어두운 톤.
 5) 크기 확인: 4배 확대 그림을 원본 옆에 놓고 *면 크기·창 크기·색 수*를 비교한다. 원본보다 작은 무늬(1화소 점)가 많으면 실패.
 6) 게임 조립 규칙(SPRITE_RULES.md)대로 to_sheet → patch_yx.
금지: 큰 그림 축소, 안티앨리어싱, 색 수 12 미만, 흩뿌린 점 질감, 검은 선.
```

## 4. 다음 구현 목록 (pixel_direct.py)
- `checker(poly, c1, c2)`: 다각형 안에 체크 디더를 채운다.
- `stripes(rect, c1, c2, w=2)`: 벽 면 위 세로 줄무늬.
- `tree(a, b, size)`: b17 나무 덤프를 기준으로 한 잎덩이 군집(색 6단계).
- `ground_shadow`: 접지 그림자.
- 위를 적용해 춘포역을 다시 그린 뒤 전수관·야구장·롯데시네마·예술의전당·도서관·성당 순서로 진행.
