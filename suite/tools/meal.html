급식비(매식비) 정산 엑셀 생성기

인사랑 프로그램에서 내려받은 초과근무 내역 엑셀을 넣으면, 평일 20시 이후 야간근무자를 자동으로 뽑아 급식확인서 · 급식지급 상세내역 · 초과근무내역 3개 시트가 담긴 정산 엑셀을 만들어 드립니다. 기존에 쓰던 정산 양식 파일을 함께 올리면 직원 명단과 순서를 그대로 이어받고, 급식처에 입력한 실제 급식인원 수에 맞춰 O표시를 날짜별로 적당히 나눠 배분합니다.

1기존양식 파일 업로드 (선택)
이전 달에 쓰던 급식비 지급내역 정산 엑셀(.xls / .xlsx)을 올리면 "급식지급 상세내역" 시트의 직원 명단과 순서를 그대로 이어받습니다. 올리지 않으면 아래 초과근무 내역에서 발견되는 순서대로 직원 명단이 작성됩니다.
클릭하거나 파일을 여기로 끌어다 놓으세요
.xls / .xlsx 파일 지원 · 선택 사항
2초과근무 내역 엑셀 업로드
인사랑에서 다운로드한 "초과근무 내역" 엑셀 파일(.xls / .xlsx)을 올려주세요. No, 근무일자, 부서, 직급, 성명, 휴일구분, 출근(실제), 퇴근(실제), 총초과(분), 근무내역 컬럼을 자동으로 찾아 분석합니다.
클릭하거나 파일을 여기로 끌어다 놓으세요
.xls / .xlsx 파일 지원

최대 급식 가능 인원(끼)
최대 급식 가능 인원은 휴일구분 = 평일 이면서 퇴근(실제)가 20:00 이후인 날의 (직원×일자) 조합 수입니다. 실제로 O표시가 들어가는 인원은 급식처별로 입력한 급식인원 합계만큼만, 날짜별로 적당히 나눠 배분됩니다.
▸ 급식지급 상세내역 미리보기 열기
3급식처 · 급식인원 입력
식사를 제공한 급식처(식당)와 인원을 나눠서 입력하세요. 지급액은 인원 × 9,000원으로 자동 계산됩니다. 여기에 입력한 급식인원 합계만큼만 급식지급 상세내역 시트에 O표시가 들어가며, 최대 가능 인원을 모두 채우지 않고 날짜별로 적당히 나눠서 배분됩니다.
연번급식처급식인원단가지급액
단가: 9,000원 (고정)
4확인자 정보 (선택)
급식확인서 하단에 표시될 확인자 직급/성명입니다. 비워두면 공란으로 출력됩니다.
5정산 엑셀 생성
아래 버튼을 누르면 급식확인서 / 급식지급 상세내역 / 초과근무내역 3개 시트가 포함된 엑셀 파일이 다운로드됩니다.
엑셀 파일을 업로드하면 여기에 인식 결과와 다운로드 버튼이 표시됩니다.
업로드한 파일은 브라우저 안에서만 처리되며 서버로 전송되지 않습니다.
