# DeskCalendar

바탕화면 위젯형 달력 + 할 일 / 메모. 디자인: Notion · Linear · Windows 11 풍 다크 테마.

## exe 받기 (Windows)
GitHub 저장소 오른쪽 **Releases → "DeskCalendar 최신 빌드" → Assets → `DeskCalendar.exe`** 를 내려받아 실행합니다.
(직접 빌드하려면 Windows에서 `build.bat` 실행 → `dist\DeskCalendar.exe`)

## 사용법
- **평소**: 달력만 바탕화면에 떠 있습니다. **날짜를 클릭하면** 오른쪽에 입력 패널이 열리고, 같은 날짜를 다시 누르거나 ✕ / Esc 를 누르면 닫힙니다.
- **기간 일정**: 달력에서 **시작일 → 종료일로 끌어서** 선택한 뒤 입력하면 기간 일정이 됩니다. 달력에는 날짜 칸을 가로로 이어 붙인 막대로 보입니다. (우클릭 → 하루 일정으로 바꾸기)
- **이동**: 맨 위 `⋯⋯⋯` 막대나 월 제목을 끌어서 옮기기 (⚙ 메뉴 → 위치 고정으로 잠금)
- **크기**: 오른쪽 아래 모서리 끌기 / Ctrl+마우스 휠 / ⚙ 메뉴 → 크기 (70%~200%)
- **빠른 입력**: Ctrl+Alt+Space → 오늘 날짜 입력창으로 바로 이동. `14:30 팀 회의` 처럼 쓰면 시간 태그로 저장
- **중요도 색**: 입력창 아래 ● 4개(매우 중요/중요/보통/낮음) 선택 (Ctrl+1~4). 목록의 ● 를 누르면 변경. 달력 색·정렬에도 반영
- **완료**: 동그라미를 누르면 체크 + 취소선. 달력에도 취소선으로 표시
- **보관함**: 상단 `보관함` 버튼. 날짜 없이 적어 두었다가 `꺼내기`로 원하는 날짜(또는 끌어서 고른 기간)에 옮김. 할 일 우클릭 → 내일로 미루기 / 보관함으로 / 중요도 / 삭제
- **글꼴**: ⚙ 메뉴 → 글꼴 (설치된 모든 글꼴 검색 가능)
- **공문 PDF**: 상단 `공문 PDF` 버튼 → 글자가 선택되는 PDF를 고르면 날짜·시간·기한·기간(예: 4. 13. ~ 10. 16., 4월~9월)을 찾아 후보 목록으로 보여 주고, 체크한 것만 일정에 추가 (스캔 이미지 PDF는 불가)
- 데이터: `%APPDATA%\DeskCalendar\data.json`
