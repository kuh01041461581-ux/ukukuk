# 국가무형유산 출석체크

- 단체(약 6개) 대표자: `/` 에서 단체·PIN 선택 → 날짜별 강의 목록에서 근로자별 출석/지각/결석 체크 후 저장
- 관리자: `/admin` → 날짜별 전체 현황(강의 × 단체), 단체·근로자·강의 설정, CSV 내보내기

실행: `ADMIN_PASSWORD=원하는비밀번호 node server.js` (기본 3000 포트, 기본 비밀번호 `admin1234`)
데이터는 `data.json` 에 저장됩니다(없으면 샘플 데이터로 자동 생성 — 관리자 페이지에서 실제 값으로 수정).

## 명부 엑셀 가져오기
관리자 → 단체·강의 설정 → "명부 엑셀 가져오기"
- 파일: .xlsx / .xls / .csv (한글 CSV 인코딩 자동 판별)
- 첫 줄에 `단체 · 이름 · 전화번호` 제목(소속/성명/휴대폰 등 비슷한 이름도 인식), 제목이 없으면 이 순서로 가정
- 전화번호는 전체든 뒤 4자리든 되며 뒤 4자리만 저장
- 미리보기 확인 → "추가·갱신"(기존 유지) 또는 "전체 교체" → 반영 → **설정 저장**
- 같은 단체·같은 이름은 같은 사람으로 보고 QR/기기 등록을 유지합니다 (동명이인은 이름에 (A)처럼 구분 표기)
