# 익산타이쿤 도트 제작 규칙

건물 도트는 **원본과 똑같은 방식(게임의 조각 규칙)** 으로 만든다. 한 장짜리 그림을 그대로 넣으면 게임 안에서 조각이 흩어져 깨진다.

## 1. 게임이 건물을 그리는 법

건물 시트(`data1.pak` 의 `b#.d`, 폭 96)는 한 장으로 그려지지 않는다. `yx.d` 의 조각표에 따라 잘라서 붙인다.

시트 구조 (높이 H):

| 구역 | 시트 줄 | 그려지는 자리 |
|---|---|---|
| 위쪽 띠 조각 | 0 ~ my | 세로는 제자리, 가로는 조각마다 정해진 만큼 이동 |
| 메인 `(0, my, 96, mh)` | my ~ my+mh | 제자리 |
| 바닥 끝 조각 | 마지막 8줄 (H-8 ~ H) | 왼쪽 64칸 → (16, my+mh), 오른쪽 32칸 → (32, my+mh+8) |

- 항상 `H = my + mh + 8` 이다.
- 바닥 마름모는 2:1 비율이고, 가장 넓은 줄은 `H - 16` 이다. 아래 끝은 `H + 8` 까지 내려간다(바닥 끝 조각이 만든다).
- 띠가 아닌 조각(차, 깃발, 옆에 따로 놓인 탑 꼭대기 등)은 별도 자리에 그려진다. 새 건물에서는 `yx.d` 에서 1x1 로 줄여 끈다.
- 조각의 화면 위치는 건물 종류별로 고정이다. `yx.d` 에서 바꿀 수 있는 것은 조각의 시트 위치와 폭뿐이다.

## 2. 만드는 순서

1. 완성 그림을 그린다. 폭 96, 높이 `H + 8`, 바닥은 2:1 마름모(가장 넓은 줄 `H - 16`).
   `make_iksan_buildings.Sc` 를 쓰면 `Sc.OVR = (H + 8, H - 16)` 로 맞춰진다.
2. `tools/strips.py` 의 `to_sheet(k, F)` 로 조각 칸에 잘라 넣는다. 띠 조각은 오른쪽으로 넓히고 덧조각은 끈다.
3. `patch_yx()` 로 `mod/yx.d` 를 고친다.
4. `compose(k, 시트, 조각)` 으로 게임이 조립한 모습을 확인한다.
5. 건설 목록에 나오는 건물은 실제 게임 화면에서 확인한다.

이 과정은 `tools/build_sprites.py` 가 한 번에 한다. **빌드 스크립트는 이것만 부른다.** 생성기를 따로 돌려 `work/pak_mod` 에 직접 쓰지 않는다(빌드 때 지워지고 다시 만들어진다).

새 건물을 추가할 때는 `build_sprites.py` 의 `ITEMS` 에 `건물 번호: 그리는 함수` 를 넣는다.

## 3. 띠 조각의 가로 위치

- 게임 기록으로 확인한 값은 `strips.KNOWN_L` 에 있다.
- 나머지는 `strips.solve_L()` 이 원본 그림의 이어짐으로 추정한다. 확인된 11개 값과 전부 일치했다.

## 4. 지형 조각 (`d#.d`, 64x64)

- 지형은 조각 규칙이 없다. 원본 조각 위에 덧칠한다.
- 도로·울타리·집을 지우지 않는다. 바꿀 화소만 색으로 골라 칠한다.
- 이웃 조각과 이음새가 맞도록 원본의 명암을 그대로 살린다.

## 5. 원본에 글자·색만 고칠 때

- 한 조각에만 속한 자리를 고친다. 조각이 겹치는 자리에 그리면 같은 그림이 두 번 찍힌다.
- 마지막 8줄(바닥 끝 조각)에는 건물 그림을 넣지 않는다.

## 6. 확인 방법

- `python3 -I tools/build_sprites.py 전시.png` : 변환한 건물 전체를 게임 조립 방식으로 본다.
- 하니스(`st2android/test/JvmRun.java`, `REPL` 모드)로 튜토리얼을 자동으로 넘긴 뒤 건설 목록을 열어 실제 화면을 찍는다.
- 원작 그림이 들어간 미리보기는 저장소에 올리지 않는다.
