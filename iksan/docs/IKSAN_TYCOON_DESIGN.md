# 익산타이쿤 기획 초안 (v0.1)

> 상태: **조사 초안**. 지리·행정구역은 검색 결과(아래 출처)와 일반 지식으로 정리했고, 위치 관계·읍면동 수는 **익산시청 공식 행정구역도로 검증 필요**. 이 환경에서는 위키/통계 사이트 접속이 막혀 표·지도를 직접 읽지 못했다.

## 1. 확인된 사실 (출처 있음)
- 인구 약 26.7만 명(2026-06 행안부 주민등록 기준), 행정구역 51개. 인구 상위: 영등동 31,262 · 부송동 29,901 · 모현동1가 26,888 · 어양동 21,441 · 마동 18,425. (k-calc.com 요약)
- 지형: 북쪽 **미륵산**, 남쪽 김제 **모악산** 사이의 평야 분지, 동쪽은 노령산맥, 가운데로 **만경강**이 흐름. 유적 대부분이 만경강 수계. (전북일보 칼럼 요약)
- **금마면·왕궁면**에 백제 유산 밀집: 미륵사지(금마, 세계유산), 왕궁리 유적(왕궁). 왕궁면에는 보석 테마 관광지.
- 호남선·전라선 교차, 장항선 종착, **KTX/SRT 익산역**. 전북 제2의 도시.
- 산업: 익산국가산업단지(1970 지정, 노후 단지 재생 사업), 제3일반산업단지 확장(삼기면·낭산면 일대, 2025 승인).
- 함열읍: 고추장(장류) 체험관 등 식품 관련.

## 2. 권역 나누기 (제안)
서울타이쿤은 **4~5개 권역(강북/강남/강동/강서 등) × 구역(블록)** 구조. 익산도 같은 틀로 가능하다. 피처폰 제약(176×208, 메모리)이 없으므로 **5개 권역 + 권역당 3~5개 구역(총 15~20개 부지 묶음)** 으로 세분화하는 것을 권장.

| 권역(안) | 포함(안) | 성격/특색 | 게임 테마 |
|---|---|---|---|
| ① 원도심 | 중앙동·평화동·인화동·마동·남중동·동산동·창인동·송학동 | 익산역, 원도심 상권, 철도 교통 요충 | 교통·상업·역세권 재개발 |
| ② 신도심·주거 | 영등동·부송동·모현동·어양동·신동·삼성동 | 대단지 아파트, 인구 최다, 대학가(원광대 주변) | 주거·교육·복지 |
| ③ 백제문화 | 금마면·왕궁면·낭산면(북부, 미륵산 일대) | 미륵사지·왕궁리 유적·서동공원·보석박물관 | 관광·문화재·축제(서동축제) |
| ④ 산업·식품 | 삼기면·함열읍·황등읍·용동면·왕궁(식품클러스터) 일대 | 국가/일반 산단, 식품, 석재(황등) | 산업·일자리·물류 |
| ⑤ 농업·강변 | 웅포·망성·성당·용안·함라·여산·춘포·오산면 | 평야·금강/만경강 하천, 한옥마을, 농산물 | 농업·환경·재해(홍수) |

- 구역 세분화 예: ①을 [역세권 / 중앙시장 / 동산·마동 / 송학·창인] 4구역으로. 읍면동 경계는 *참고*일 뿐, 게임 구역은 **체감 생활권 + 랜드마크 중심**으로 새로 정의해도 됨.
- 서울판 매핑: 강북→원도심(번화·밀집), 강남→신도심(고급 주거·학군), 강동/서→ 외곽(개발 여지 큼). 익산판은 **백제문화 권역**이 서울에 없는 고유 축(관광·문화재 정책).

## 3. 게임 시스템 (서울판 구조 재사용)
- 지표: 인구·예산·자재·인력·**지지도**·피로, 임기 4년(월 단위 진행, 월말 정산). 서울타이쿤의 정책/사건/뉴스 구조를 그대로 재해석.
- 익산 고유 이벤트(안): 서동축제, 보석(귀금속) 산업 부침, KTX 개통 효과, 만경강 홍수, 황등 석재 수요, 노후 산단 재생, 미륵사지 세계유산 등재 후 관광객 증가.
- 데이터 구조는 서울판 해독 결과(`seoultycoon/docs`, `assets/st2_text`)를 **형식만** 참고하고 내용은 전부 새로 작성.

## 4. 그래픽 방식: 도트 vs 벡터
**결론: 도트(픽셀 아트) 권장.**
- 서울타이쿤의 정체성이 아이소메트릭 도트 → 팬 기대·톤 일치.
- 해상도 독립: 정수 배율 확대로 스마트폰/PC 모두 선명. 벡터는 도트풍 UI와 섞이면 이질적.
- **직접 제작 가능성**: 내가(AI) 생성하기엔 도트가 유리 — 팔레트·타일 규격을 정해 **코드(Python/PIL)로 아이소 타일·건물을 절차적으로 생성**하고, 변형(색 교체·층수·창문 패턴)으로 수백 종 확장 가능. 벡터(SVG)는 만들긴 쉽지만 도트풍 일관성을 맞추기 어렵다.
- 규격(제안): 타일 64×32 아이소(다이아몬드), 건물 64~64×96, 팔레트 32색 고정, 글꼴 Galmuri11(도트, OFL), 정수 배율 2~4×.
- 에셋 추출 대신 **새로 그리므로 저작권 문제 없음**(원작 그래픽 미사용). 원작 스프라이트는 규격 참고용으로만.

## 5. 기술 스택 제안
- Unity는 필수 아님. 이 환경에는 Unity 가 없어 **빌드·검증 불가** → **HTML5 Canvas(TypeScript/JS) 게임 + PWA**, 안드로이드는 이미 구축한 APK 파이프라인(aapt/dx/apksigner)으로 **WebView 래퍼 APK** 를 만들어 배포. PC 는 브라우저로 바로 실행, 스마트폰은 APK/홈화면 추가. 터치·키보드·패드 입력은 기존 `GameView` 아이디어 재사용.
- 나중에 Unity 로 옮길 수 있게 **데이터(JSON: 구역·건물·정책·사건)와 렌더링을 분리**.

## 7. 사용자 요구 반영 (v0.2)
### 7.1 서울타이쿤에서 가져올 것 / 새로 만들 것
- **가져올 것(구조)**: 진행 방식(월 단위 진행·정산), 부지 선택→방문/건설 흐름, 타일(부지) 배치 방식, 턴, 비서 제도(자문·제안), 사건/뉴스 이벤트 틀.
- **새로 쓸 것(내용)**: 대사·뉴스·이벤트 문구, 지명·시설, 그래픽, 사운드는 전부 익산판으로 새로 작성. 규칙·구조는 재사용해도 되지만, 원작 텍스트·이미지를 그대로 쓰면 출시 시 저작권 위험이 있으므로 **형식만 참고**한다(개인 소장/시험 단계에선 영향이 작지만, 공개 배포를 염두에 두면 처음부터 새로 쓰는 편이 안전).
- **원작 텍스트 조사 결과**: 서울타이쿤 2 텍스트(대사/사건/뉴스)에서 연임·재선·탄핵·뇌물/뒷돈 이벤트는 **찾지 못했다**(키워드 검색: 연임·탄핵·뒷돈·비자금·불신임 등 0건, 감사/선거는 일반 문장에 우연히 포함). 즉 아래 선거·연임·뒷돈·감사·탄핵 시스템은 **원작에 없는 익산판 신규 시스템**으로 설계한다.

### 7.2 임기·선거·연임 (최대 12년)
- 임기 4년 = 48개월. 임기 종료 시 **선거 이벤트**: 득표율 = 지지도(기본) + 보정(공약 이행·사건 대응·예산 건전성·스캔들 감점).
- 당선 시 **연임**(최대 2회 → 4+4+4 = 최대 12년). 연임 확정 때마다 선택창: **「엔딩 보기」 / 「계속 플레이」**. 12년(3임기) 종료 시에는 엔딩 고정(추가 플레이 여부는 '자유 모드'로 별도 제공 가능).
- 낙선 시 즉시 낙선 엔딩(지지도·업적 요약). 엔딩은 업적(인구·예산·문화재·산업·복지·청렴도) 기반 등급 + 후일담.
- 달력: 게임 시작 시점을 **실제 오늘 날짜**로 두거나(권장), 선택 시작월을 지원. 월 진행은 게임 월 = 달력 월.

### 7.3 부패·감사·탄핵
- **뒷돈 이벤트**(건설 인허가·민원·기업 후원 등): 수락하면 예산/자재 보너스 + **청렴도 하락, 감사 위험도(0~100) 상승**, 거절하면 청렴도 상승·지지도 소폭 상승.
- **감사**: 위험도가 임계치를 넘으면 감사 이벤트 발생(경고 → 지지도 하락·예산 환수). 짧은 기간에 반복 수락하면 위험도가 더 빨리 오르고, **감사 누적 2~3회 시 탄핵 절차** → 즉시 게임오버(탄핵 엔딩). 청렴도를 올리는 정책·사건 대응으로 위험도 감소 가능.
- 비서 연동: 비서가 뒷돈을 권하거나 경고하는 대사(비서 성격별), 언론/시민단체 뉴스 이벤트로 소문→감사 전조 표현.

### 7.4 실제 날짜 연동 익산시 행사
- 월별 이벤트 테이블(JSON)로 관리: `{month, name, 권역, 효과(지지도/관광/예산/인구), 문구}`. 아래는 **후보 목록(날짜·개최월 검증 필요)**: 서동축제(금마, 백제 서동 설화), 보석 관련 행사(왕궁 보석박물관), 국화 축제류, 함라 한옥마을 행사, 익산 미륵사지·왕궁리 유적 문화재 행사, 장류(함열 고추장) 행사, 농산물 수확기(쌀·고구마 등), 호우·홍수기(만경강, 여름), 한파/폭설(겨울).
- 이 표는 **익산시청/문화관광 공식 일정으로 확인한 뒤** 확정(현재 네트워크 제한으로 미확정 — 개최월을 지어내지 않는다).
- 사용자가 입력한 날짜가 아닌 **기기 날짜**를 쓰면 같은 달에 실제 축제가 열리는 느낌을 줄 수 있음(옵션으로 끌 수 있게).

### 7.5 구현 우선순위(제안)
1. 월 진행 + 지표 + 선거/연임/엔딩 선택(시스템 뼈대) — 데이터 JSON 로 분리.
2. 부패/감사/탄핵 로직(위험도·청렴도).
3. 월별 이벤트 테이블 + 익산 행사(검증 후).
4. 도트 타일·건물 생성기 + 샘플 맵 → 권역 프로토타입.

## 8. 시스템 설계 보강 (v0.3) — "가볍게, 조금만 세분화"
### 8.1 참고 게임에서 가져올 개념 (깊게 가지 않음)
- **심시티류**: 구역(존) 개념, 예산 균형, 시민 만족/지지도, 재난·사건. → 가져올 것은 *예산 균형 + 지지도 + 사건* 3가지뿐. 교통·전력·수도 같은 세부 시뮬레이션은 **넣지 않는다**(서울타이쿤처럼 "건물 효과 = 수치 가감").
- **로그라이크식 선택 이벤트(예: 의사결정형 게임)**: 한 장의 카드에서 선택→수치 변화. 뒷돈·감사·선거 이벤트는 이 형식으로 구현(저비용·확장 쉬움).
- 서울타이쿤 틀 유지: 월 진행, 부지→방문/건설, 비서 제안, 뉴스/사건.

### 8.2 예산 — 단순화안 (채택 권장)
- **예산 하나**로 표시하되, 수입원을 3줄로만 구분: ① 시 자체수입(세금) ② **정부지원(국비+도비 통합)** ③ 기타(후원·수익).
- 예산이 부족하면 커맨드 **「예산 확보 활동」**: 정치력·피로를 소모해 정부지원 확보 시도(성공률 = 정치력·지지도·사업 명분). 
- (확장 옵션, 나중에) 정부지원을 국비/도비로 분리: 국비=국회/중앙부처 방문, 도비=도청 방문. 초기엔 통합.

### 8.3 정치력(PL) 스탯
- 0~100. 오르는 법: 국회·도청 방문 성공, 업적(축제 성공·사업 완료), 비서 정치 보좌. 내리는 법: 감사·스캔들·낙선 위기.
- 쓰임: 예산 확보 성공률, 인허가 이벤트 협상, 선거 득표 보정, 뒷돈 거절 시 불이익 완화.

### 8.4 시 밖 이동 커맨드(월 단위 행동)
- 「국회 방문」「도청 방문」「중앙부처 방문」: 이동 기간(대개 1개월 중 일부) + **피로 증가** + 시내 업무 공백(사건 대응 지연). 결과: 정부지원 예산·정치력·인맥 아이템.
- 시 안에 머무를 때와 비교한 기회비용으로 선택의 긴장감.

### 8.5 피로도
- 서울타이쿤에도 '피로' 지표가 있음(원작 하단 바에 표시, 과로 시 입원·휴가 이벤트 확인). 동일하게 **행동마다 피로 +, 휴식/축제 참석/휴가 −**, 임계치 초과 시 과로 입원(한 달 행동 불가·지지도 소폭 하락), 반복 시 탄핵 외에 **사퇴 위험** 이벤트는 넣지 않고 단순 유지.

### 8.6 행정구역/권역 (현재까지 확인된 범위)
- 행정복지센터 목록(검색 확인): 남중동·동산동·마동·모현동·삼성동·송학동·신동·어양동·영등(1·2)동·인화동·중앙동·평화동. 인구표에는 부송동·영등동·모현동1가가 별도 표기(통계 표기와 행정동 표기가 다름).
- 읍·면(검색 확인): 함열읍, 왕궁면, 금마면, 오산면, 황등(자료에 따라 '읍/면' 표기 상이). 그 외 읍면(낭산·삼기·여산·춘포·웅포·망성·성당·용안·용동·함라 등)은 **공식 목록으로 미검증**.
- 한계: ko.wikipedia.org, 시청 사이트는 네트워크 정책으로 접속 불가 → **전체 읍면동 표·지도는 아직 못 읽음**. 네트워크가 열리면 §2 권역표를 실제 목록으로 확정.
- 잠정 권역 묶음(5권역)은 §2 유지, 구역(블록) 세분화는 인구 상위 동(영등·부송·모현·어양·마)을 독립 구역으로 두는 방향.
