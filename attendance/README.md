# 국가무형유산 출석체크

- 단체(약 6개) 대표자: `/` 에서 단체·PIN 선택 → 날짜별 강의 목록에서 근로자별 출석/지각/결석 체크 후 저장
- 관리자: `/admin` → 날짜별 전체 현황(강의 × 단체), 단체·근로자·강의 설정, CSV 내보내기

**배포(무료)**: `DEPLOY.md` 참고 (Cloudflare Workers). 
**로컬 실행**: `ADMIN_PASSWORD=원하는비밀번호 node server.js` (3000 포트, 샘플 데이터 포함, 비밀번호 미설정 시 `admin1234`)
데이터는 `data.json` 에 저장됩니다(없으면 샘플 데이터로 자동 생성 — 관리자 페이지에서 실제 값으로 수정).

## 명부 엑셀 가져오기
관리자 → 단체·강의 설정 → "명부 엑셀 가져오기"
- 파일: .xlsx / .xls / .csv (한글 CSV 인코딩 자동 판별)
- 첫 줄에 `단체 · 이름 · 전화번호` 제목(소속/성명/휴대폰 등 비슷한 이름도 인식), 제목이 없으면 이 순서로 가정
- 전화번호는 전체든 뒤 4자리든 되며 뒤 4자리만 저장
- 미리보기 확인 → "추가·갱신"(기존 유지) 또는 "전체 교체" → 반영 → **설정 저장**
- 같은 단체·같은 이름은 같은 사람으로 보고 개인 링크·기기 등록을 유지합니다 (동명이인은 이름에 (A)처럼 구분 표기)

## 구조
- `src/core.js` — API·출석 규칙·통계 (Node/Cloudflare 공용)
- `src/worker.js` — Cloudflare Worker + Durable Object(데이터 저장, 요청 직렬 처리)
- `server.js` — 로컬 Node 서버(파일 저장)
- `public/` — 화면 (출석 `/c/`, 개인 `/m/`, 관리자 `/admin` — PC는 왼쪽 메뉴, 휴대폰은 하단 탭 바)

## 강의 만들기·자동 출석 개설
- 관리자 → 강의 만들기: 강의 이름, 매주 반복(요일 여러 개) 또는 하루만, 시간·날짜는 **직접 입력**(`10시 반`, `1030`, `오후 2시`, `1120`, `내일` 등) 또는 버튼 선택. 입력 즉시 자동 저장
- 강의마다 **매주 같은 출석 링크**(`/c/…`)가 하나 생깁니다. 한 번만 보내 두면, 강의 날에 링크를 열 때 그날 출석이 자동으로 열립니다(강의가 없는 날은 "오늘은 강의가 없습니다 · 다음 강의 …" 안내)
- 서버가 매일(한국 시간 자정 직후, 또는 그날 첫 접속 때) 오늘 열리는 강의의 출석을 자동 개설합니다. 휴강일·기간 밖 날짜에는 열리지 않습니다

## 추가 기능 (운영 편의)
- **출석부 인쇄**: 통계 탭 → 단체를 고르고 [출석부 열기] → 인쇄 또는 PDF 저장 (○출석 △지각 ×결석, 담당자·확인란 포함)
- **확인이 필요한 기록**: 통계 탭 하단. 위치 오차가 크거나(±100m 초과) 교육장 경계(허용 반경의 85% 이상)에서 출석했거나, 같은 휴대폰으로 여러 명이 출석한 기록을 표시
- **백업·복원**: 설정 탭 하단. 전체 백업 파일 내려받기/복원, 서버 자동 백업(매일, 명단·강의·설정 14일치)에서 날짜를 골라 되돌리기
- **오늘 강의 안내문 한 번에 공유**, **기기 변경 요청 모두 승인**: 현황 탭
- **글자 크기 조절**(가−/가+): 출석자 화면 맨 위. 선택은 그 휴대폰에 저장
- **홈 화면에 추가**: 관리자 페이지를 휴대폰 홈 화면에 앱처럼 추가 가능(안드로이드 크롬: 메뉴 → 홈 화면에 추가 / 아이폰 사파리: 공유 → 홈 화면에 추가)
