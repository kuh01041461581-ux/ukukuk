# 피처폰 게임 모음 (안드로이드 APK + PC)

옛 피처폰(2006~2009) 게임 8개를 에뮬레이터 [WIE](https://github.com/dlunch/wie)(MIT)에 묶어서
**스마트폰 APK**와 **PC(브라우저)** 양쪽에서 실행되게 만든 것입니다.

| # | 게임 | 원래 형식 |
|---|------|-----------|
| 1 | 메이플-마법사편 | 피처폰 네이티브(KTF) |
| 2 | 메이플스토리(그래텍) | KTF |
| 3 | 메이플-궁수편 | KTF |
| 4 | 메이플스토리 도적편 | KTF |
| 5 | 2006월드올림픽 | KTF |
| 6 | 당신은 야구감독 | LGT(WIPI) |
| 7 | 메이플스토리2007 | LGT(WIPI) |
| 8 | 대해적시대 | SK텔레콤 J2ME |

## 게임별 APK (권장)

`apk/build_each.py` 가 **게임마다 따로** APK 를 만듭니다(8개, 각 약 8.5MB). 각 APK 는 패키지명이 달라서(`net.featurephone.g.<게임>`)
따로 설치·삭제되고, **저장도 게임별로 분리**되며, 아이콘을 누르면 라이브러리 없이 **바로 그 게임이 실행**됩니다.
(아이콘은 SDK 없이 만들 수 없어서 기본 안드로이드 아이콘이고, 앱 이름만 게임 이름입니다.)
`FeaturePhoneGames.apk`(8종 묶음)는 한 앱에서 모아 보고 싶을 때 쓰세요.

## Windows 에뮬레이터

`x86_64-pc-windows-gnu` 로 크로스 컴파일한 `wie.exe`(추가 DLL 불필요). 빌드: `cargo build --release --target x86_64-pc-windows-gnu`
(Linux 에서 `gcc-mingw-w64-x86-64` 필요, `.cargo/config.toml` 에 `linker = "x86_64-w64-mingw32-gcc"`). **Windows 에서 실행해 보지는 못했습니다.**

## 받을 파일 (`dist/`)

- `FeaturePhoneGames.apk` — 안드로이드 7.0 이상. 설치 후 처음 실행하면 8개 게임이 자동으로 라이브러리에 들어갑니다.
- `FeaturePhoneGames-PC.zip` — 압축을 풀고 `PC실행.bat`(Windows) 또는 `pc_start.sh`(Mac/Linux)를 실행하면 브라우저가 열립니다. Python 3 이 필요합니다.

## 조작

### 스마트폰 (화면 아래 탭에서 선택, 기억함)
- **터치 패드**: 방향 입력 + `확인 / 좌메뉴 / 우메뉴 / 취소 / 5` + `숫자`(0~9 * # 패드 펼치기)
  - 방향 입력은 **방향 버튼(기본)** 과 **조이스틱** 중에서 고릅니다(방향 버튼 아래 작은 버튼 또는 ⚙ 설정). 방향 버튼은 손가락을 미끄러뜨리면 대각선(8방향)도 됩니다.
- **피처폰 키패드**: 방향키·OK·좌/우메뉴·통화·취소·숫자 키패드(원래 폰 배열)
- **⚙ 조작 설정**
  - 방향 버튼 / 그 외 버튼의 **최소 누름 시간**(짧게 톡 쳐도 게임이 인식하도록)
  - 꾹 눌렀을 때 **반복 입력**: 켜기/끄기, 시작 지연, 간격 (옛 게임은 반복 입력으로 이동·메뉴 이동을 처리합니다)
  - 조이스틱 **민감도**
  - **진동**: 켜기/끄기, 세기(약·보통·강), 방향 입력에도 진동할지, **진동 시험** 버튼
  - 기본값 버튼

### PC 키보드 (웹 PC판, Windows/Linux 에뮬레이터 모두 동일)
```
=========== 조작 키 (PC) ===========
 방향 .......... ← ↑ ↓ →
 확인 (OK) ..... Enter 또는 Space
 취소 (CLR) .... Backspace 또는 Esc
 좌메뉴 ........ V 또는 왼쪽 Shift
 우메뉴 ........ B 또는 오른쪽 Shift
 통화 / 종료 ... F1 / F2
 숫자 0~9 ...... 윗줄 숫자키 또는 오른쪽 숫자패드
 폰 배열 숫자 .. Q W E = 4 5 6 / A S D = 7 8 9 / Z X C = * 0 #
 * 와 # ........ 숫자패드의 * 와 /
====================================
```
PC 웹판은 화면 버튼 아래에 대응 키(Enter, V, B, Esc, F1)가 표시되고, 아래쪽에 키 안내 표가 있습니다.

## 저장

게임 저장은 앱 전용 저장소(WebView/브라우저 IndexedDB)에 게임별로 들어가며 앱을 껐다 켜도 유지됩니다.
**주의**
- APK를 **지우거나 앱 데이터를 삭제하면 저장도 사라집니다.**
- 업데이트(덮어 설치)하려면 같은 서명 키(`apk/featurephone.p12`)로 만든 APK여야 합니다. 다른 키로 만든 APK는 먼저 지워야 해서 저장이 날아갑니다.
- PC는 같은 브라우저·같은 주소(`127.0.0.1:8765`)에서 열어야 저장이 이어집니다. 브라우저 방문 기록/사이트 데이터를 지우면 사라집니다.

## 직접 만들기

1. WIE 원본(`dlunch/wie`, 커밋 `34abac9`)을 받아 `wie-featurephone.patch` 적용 → `npm install && npm run build:prod`
   (필요: Rust + wasm32 타겟 + wasm-pack, Node). `wasm-opt` 를 받을 수 없는 환경이라 최적화는 껐습니다.
2. 결과물 `wie-web/dist` 를 `www/` 로 복사하고 `www/games/` 에 게임 zip 과 `apk/games.json` 을 넣습니다.
3. `apk/build_apk.py www 출력.apk` — Android SDK 없이 JDK + `lib/`(apksig.jar, dx.jar, android11.jar: Maven Central) + `pip install pyaxml` 만으로 조립·서명합니다.

## 확인한 것 / 확인하지 못한 것

확인함 (Chromium + 폰 크기·터치 모드, APK 안의 파일을 WebView 와 같은 가상 주소로 제공해서):
- 8개 게임 모두 실행되어 타이틀/메뉴까지 표시, `확인` 터치로 게임 진행(마법사편은 스토리 시작까지 확인)
- 조이스틱·버튼·키보드 입력 전달, 두 패드 전환
- 8개 게임을 한 번씩 실행한 뒤 새로고침해도 저장 데이터와 라이브러리 8개가 그대로 유지됨
- APK: v2 서명 검증 통과, 매니페스트·메인 액티비티 정상 인식

**확인하지 못함** (실제 안드로이드 기기/에뮬레이터가 없었음):
- APK 를 **실제 폰에 설치해서 실행해 본 적은 없습니다.** 앱 껍데기(`MainActivity.java`)와 아이콘 없는 매니페스트는 폰에서 처음 검증되는 부분입니다.
- 게임별 "저장 지점까지 직접 플레이"는 하지 않았습니다. 마법사편·메이플스토리(그래텍)·파일 저장 게임들은 저장 기록이 생성·유지되는 것을 확인했고, 궁수편·도적편은 짧은 실행에서 기록이 아직 생기지 않았습니다(진행 중에 저장하는 방식일 수 있음).
- Windows 에서 `PC실행.bat` 은 실행해 보지 못했습니다(Python 실행기는 Linux 에서 확인).
- 처음 실행 때는 게임마다 변환 작업으로 10~40초 걸렸습니다(변환 결과를 저장하는 구조가 있지만, 두 번째 실행이 얼마나 빨라지는지는 측정하지 않았습니다).
- 소리(MIDI/효과음)는 소리 장치가 없는 환경이라 확인하지 못했습니다.

## 기존 APK 게임 6개 (검은방 1~4, 메이플 도적편·시그너스기사단) — 재서명판

원본 APK 에는 `targetSdkVersion` 이 없어서 안드로이드가 "아주 오래된 앱"으로 보고 **새 안드로이드에서는 설치를 거부**합니다
(Android 14 는 23 미만, **Android 15 이상은 24 미만**을 거부하는 것으로 알려져 있습니다).
`tools/retarget.py` 로 매니페스트에 `targetSdkVersion=28` 과 옛 HTTP 라이브러리 선언(`org.apache.http.legacy`, 선택 사항)만 추가하고 다시 서명한 것이 `*-재서명.apk` 입니다.
(요소·속성을 순서와 무관하게 비교해서 그 둘 외에는 원본과 같음을 확인했고, 서명 검증은 Android 7.0 기준으로 통과했습니다.)

- 원본이 이미 설치돼 있으면 **먼저 지워야** 합니다(서명이 다르면 덮어쓸 수 없음).
- **가장 큰 한계**: 6개 모두 **32비트(`armeabi`) 네이티브 라이브러리만** 들어 있습니다. **64비트 전용 폰은 설치 자체를 거부합니다**(`INSTALL_FAILED_NO_MATCHING_ABIS`). 요즘 폰 다수가 여기에 해당하고, 재서명으로는 해결되지 않습니다.
  - 이 경우 방법: ① 32비트 앱을 지원하는 구형 폰, ② PC 의 안드로이드 에뮬레이터(ARM 변환 지원: BlueStacks, Nox 등), ③ 같은 게임의 피처폰 버전(이 프로젝트의 APK)을 사용.
- 이 6개는 **폰에서 설치·실행해 보지 못했습니다.**
- 크랙 ARM 파일은 사용하지도 수정하지도 않았습니다.

## 에뮬레이터 단독 실행 (Linux)

`WIE에뮬레이터-Linux.zip` 의 `wie 게임.zip`. Windows/Mac 용은 이 환경에서 만들 수 없어서, 그쪽은 `FeaturePhoneGames-PC.zip`(브라우저 방식)을 쓰세요.

## 렉(느려짐) 개선 내역

측정(헤드리스 Chromium, 게임 화면에서 10초간 메인 스레드 사용률)으로 원인을 찾아 고쳤습니다.

1. **로그 출력 끄기**: 게임 함수를 호출할 때마다 경고/정보 로그를 브라우저 콘솔로 보내고 있어 CPU 를 크게 썼습니다(메이플2007은 글자 폭 경고만 1분에 7만 번). 오류만 남기도록 바꿨습니다.
2. **명령 캐시 비우기 때 불필요한 재컴파일 제거**(`wie-core-arm/src/aot.rs`): 게임이 캐시 비우기 명령을 자주 실행하면, 코드가 그대로인데도 변환해 둔 코드를 전부 버리고 다시 컴파일했습니다. 이제 변환 당시 코드 바이트와 현재 메모리를 비교해 **실제로 바뀐 영역만** 버립니다. 메이플2007: 재컴파일 40초에 731회 → 24회.
3. **최적화 빌드**: 전체 LTO·최적화 수준 3·단일 코드 생성 단위, 그리고 `wasm-opt`.
4. **화면 배치**: 게임 화면이 패드에 눌려 사라지던 문제(짧은 PC 화면) 수정. PC는 왼쪽 큰 게임 화면 + 오른쪽 패드/키 안내, 폰은 게임 화면 최소 높이 보장.

## 메이플스토리 도적편(피처폰판) 초록색 깨짐 수정

이 게임의 이미지(8비트 BMP 1,259개)는 `bfReserved1 = 1` 이고 `biClrImportant` 가 **투명색의 팔레트 번호**(상위 비트 없이)인데,
에뮬레이터는 `0x100 | 번호` 형태만 투명으로 인식해서 투명색(초록)이 그대로 칠해졌습니다.
번호만 적힌 형태도 인식하도록 고쳤습니다(팔레트 범위 안일 때만 → 표준 BMP 와 구분). 이런 이미지가 있는 건 이 게임뿐이라 다른 게임에는 영향이 없습니다.
(`wie-backend/src/canvas.rs`, 시험 추가)

## 갤럭시 S24+ 에서 재서명 APK 가 "앱이 설치되지 않음" 인 이유

검은방 1~4, 메이플 도적편·시그너스(안드로이드판)는 **32비트(`armeabi`) 라이브러리만** 들어 있습니다.
갤럭시 S24 시리즈(스냅드래곤 8 Gen 3 / 엑시노스 2400)는 **64비트 앱만 실행**하는 구성이라 이런 앱은 설치 단계에서 거부됩니다(원본 APK 도 마찬가지).
설치 프로그램이 이유를 구체적으로 알려주지 않고 "앱이 설치되지 않음" 만 보여줍니다. 재서명으로는 해결되지 않습니다.

- `tools/diag/` 는 폰이 32비트를 지원하는지 보여주는 진단 앱(`기기확인.apk`)의 소스입니다.
- 방법: ① 피처폰판이 있는 게임(메이플 도적편 등)은 이 프로젝트의 APK 사용, ② 안드로이드판만 있는 게임(검은방, 시그너스기사단)은 32비트 ARM 앱을 변환해서 실행해 주는 PC 안드로이드 에뮬레이터(BlueStacks, LDPlayer 등)를 시도(제가 확인한 것은 아님).

## 검은방1 (32비트 안드로이드 게임을 에뮬레이션으로 실행)

`android32/` 에 32비트(armeabi) 안드로이드 게임 라이브러리를 WIE 의 ARM 실행기(wasm)로 돌리는 소스가 있습니다.
갤럭시 S24+ 처럼 32비트를 못 돌리는 폰에서도 APK(웹뷰 껍데기, 네이티브 코드 없음)로 설치됩니다.
- 터치 입력·저장(IndexedDB)·소리(WebAudio)·진동 연결, 서버 접속은 "접속 실패" 화면 후 확인 → 메뉴로 진행
- 헤드리스 크롬에서 타이틀 → 새 게임 → 본편 대사 장면까지 확인(약 20~30fps). 실제 폰 설치/속도/소리/저장은 미검증

### 32비트 게임 진행 상황 (에뮬레이션 방식)
| 게임 | 상태 |
|---|---|
| 검은방1·2·3 | 타이틀/메뉴/본편 진입까지 PC(헤드리스 크롬)에서 확인. APK 제공 |
| 검은방4 | 안 됨. 게임 내부 UI 초기화 단계에서 잘못된 이미지 포인터를 만나 멈춤(STRD 정렬 패치·`__cxa_guard` 구현 후에도). 원인 추적 중 |
| 시그너스기사단·메이플 도적편(안드로이드) | 안 됨. OpenGL ES 2.0 셰이더/FBO 에뮬레이션이 필요하고 libpng 압축 해제도 맞지 않음. `android32/src/main.rs`의 `BNV=` 모드로 `OnNativeInitialize` 까지는 진행(정적 생성자, zlib, setjmp, pthread 흉내 구현) |
