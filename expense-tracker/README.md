# 일상경비·공공요금 관리 (브라우저 프로그램)

설치 없이 HTML 파일 하나를 더블클릭(크롬·엣지)해서 쓰는 프로그램입니다. 입력한 내용은 그 브라우저에 자동 저장되고, 설정 탭에서 백업 파일(.json)로 보관할 수 있습니다.

- **일상경비 집행현황**: 사무관리비·공공운영비·업무추진비·여비 — 지출액 입력, 집행률·잔액·막대그래프, 행별 지급예정 메모
- **공공요금 집행현황**: 전기·상하수도·통신 — 월별 고지서 수령 체크(미수령/수령/청구없음), 금액 입력, 자동 합계, 계약·납부번호 내장(누르면 복사), 월별 그래프
- **PDF 불러오기**: 합본예산서(세출예산사업명세서) → 총예산액·공공요금 예산, 통계목별 조회 → 지출액·원인행위

## 만드는 방법
엑셀의 계약번호·납부번호·계좌번호가 파일에 들어가므로 **완성된 HTML은 이 저장소(공개)에 올리지 않습니다** (`dist/` 는 .gitignore).

```bash
pip install openpyxl
python build.py --util 공공요금엑셀.xlsx --daily 일상경비엑셀.xlsx
# → dist/일상경비_공공요금_관리_2026.html
```

`vendor/` 의 PDF.js(Apache-2.0)는 PDF 읽기에 사용됩니다.
