# 한글 양식 생성기 (hwp_form_generator)

한글(HWP) 옆에 붙여 두는 **옆 창 프로그램**. 보고 양식을 누르고 칸을 채우면, 제목 상자·담당자 줄·□ 제목·◦ 항목·표가
**글꼴·글자 크기·자간·들여쓰기·표 테두리까지 양식 그대로** 한 번에 한글 문서에 들어갑니다.
범정부 오피스에 없는 **익산시 양식**(문화교육국 보고 / 시장님 보고 / 주간업무계획 / 주간 주요일정)이 기본으로 들어 있고,
**한글 파일 하나만 주면 새 양식을 추가**할 수 있게 설계했습니다.

## 들어 있는 양식

| 양식 | 종류 | 용도 |
|---|---|---|
| 행사 보고 (식순·시간표) | 보고서 | 행사개요 → 식순·시간표(표) → 국장님 하실 일. **문화교육국 보고** |
| 사업 보고 (개요·실적·계획) | 보고서 | 사업개요(사업비·사업내용) → 지난 실적 → 향후 계획 → 참고자료. **문화교육국 보고** |
| 시장님 보고 (보고 표지 + 세부 추진계획) | 보고서 | **시장님 보고**: 보고 내용은 항상 1장, 참고자료는 `참고자료 쪽 추가` 단추로 뒤에 새 쪽을 붙임 |
| 간부회의 표지 / 현안업무 보고(1쪽) / 참고자료 사업 카드 | 간부회의 | 날짜·시각 상자 표지, `현안업무(n) 제목(과)` + □ 금 후 계 획(◦ ▸ - 3단계), 사업명 상자 + 계장·담당자 + 지난주 실적/금후 계획 |
| 행정사무감사 표지 / 과 공통사항 목록 | 행정사무감사 | 회기·국 이름 표지, 과 이름표 + 감사자료 과 공통사항·과 요구사항 목록(과별 항목은 비움) |
| 예산 설명자료·참고자료 표지 / 사업별 설명자료(1사업 1쪽) | 예산 설명자료 | 회기·예산 제목·국(과) 표지, 정책명·단위사업·세부사업명 + 경비내역 표(머리만) + □ 사업개요/증감사유/관계법령/기대효과 |
| 주간업무계획 (국 쪽) | 주간 | 국 이름표 + ❶ 행사명 (부서 담당자 내선) + ◦ 일시/장소/… |
| 주간 주요일정 (표) | 주간 | 월~일 날짜별 시간·일정명·장소·주관부서·국장님·비고, 일정이 많으면 그날 줄이 늘어남 |

## 쓰는 법 (옆에 뜨는 위젯)

프로그램을 켜면 한글 오른쪽에 **좁은 위젯**이 항상 위에 떠 있고(한글이 켜져 있으면 자동 연결·자동으로 옆에 붙임), 양식 단추가 나열됩니다.

- **양식 단추를 한 번 클릭 → 한글에 바로 생성**: 열려 있는 문서의 커서 위치에 제목 상자·담당자 줄·□ 제목·◦ 항목이 양식 서식 그대로 들어갑니다.
  담당자·과·계·보고일은 **내 정보**(상세 입력 → 양식 관리 탭, 이 PC에만 저장)와 오늘 날짜로 자동으로 채워지고, 나머지는 한글에서 바로 고치면 됩니다.
- **주간업무계획 / 주간 주요일정 단추**: 이번 주 자료로 한 번에 생성. 주 자료는 [상세 입력 → 주간 업무]에서 한 번만 적으면 되고(또는 시 전체 주간업무계획에서 우리 국 항목만 발췌), 두 문서가 함께 나옵니다.
- **[상세 입력 · 양식 추가…]**: 칸을 직접 채워서 만들 때, 본문(`□ 제목` · `◦ 일시: …` · `- 세부` · `| 표 |`)을 입력해서 만들 때, 한글 파일 하나로 **새 양식을 추가**할 때 쓰는 창.
- 위젯 단추는 **새 문서를 만들지 않고, 지금 열려 있는 한글 문서의 커서 위치에** 서식째 넣습니다(임시 파일은 넣은 뒤 지움). 한글에 연결하지 못하면 안내만 하고 아무것도 만들지 않습니다. 새 문서/파일 저장은 [상세 입력]에만 있습니다.

명령줄도 됩니다: `python app.py --help` (화면 없이 JSON → hwpx).

## 설계 (새 양식을 파일로 받아 추가하는 구조)

```
hwp_form_generator/
  app.py              화면(인자 없음) / 명령줄(인자 있음)
  hwpgen/
    package.py        .hwpx(zip+XML) 읽기·쓰기, 문단·표 복제, id 새로 매기기
    textfmt.py        항목 이름 맞춤(일시→일    시), 날짜·요일, 본문 입력 해석(□ ◦ - | |)
    report.py         보고서 양식: register_report()(등록) + ReportForm.render()(생성)
    weekly.py         주간업무계획·주요일정 양식 + 계획 글에서 일정 뽑기(parse_plan_lines)
    registry.py       양식 목록(기본 forms/ + 내 폴더 %APPDATA%/HwpFormGenerator/forms/)
    profile.py        내 정보·주별 자료 (이 PC 에만)
    bridge.py         실행 중인 한글에 붙어 문서 끼워 넣기·글자 읽기·창 붙이기 (COM, Windows)
    gui.py            옆 창 화면
  forms/<양식id>/    form.json(이름·입력 칸·서식 규칙) + template.hwpx(틀) + protos.xml(문단·표 견본)
  tools/build_forms.py   사용자가 준 샘플 4개에서 기본 양식 4종을 만드는 스크립트
```

**서식을 그대로 내는 방법.** 한글 문서의 모양은 `header.xml` 에 번호(글자 `charPrIDRef`, 문단 `paraPrIDRef`, 칸 `borderFillIDRef`)로
정의돼 있고 본문은 그 번호를 가리킵니다. 양식을 등록할 때 샘플의 `header.xml` 을 그대로 가져오고, 본문에서
**□ 제목 줄 / ◦ 항목 줄 / 빈 줄 / 표 줄**의 모양(번호)을 '견본'으로 뽑아 둡니다. 생성할 때는 새 글자를 견본 번호에 실어 찍을 뿐이라
글꼴·크기·자간·들여쓰기가 샘플과 같습니다. 새로 만든 서식 번호가 없으니 한글이 서식을 해석 못 할 일도 없습니다.

**양식 한 개 = 폴더 한 개.** 아래 둘 중 하나로 늘립니다.
- 보고서류(제목 상자 + □ 본문): **한글 파일 하나**면 자동 등록. GUI(양식 관리 → 양식 추가) 또는
  `python app.py add-form --sample 새양식.hwpx --id my_form --name "이름" --title "샘플 제목 글자"`
  - 본문 영역(□ 제목 줄이 있는 곳, 표 칸 안이어도 됨)을 자동으로 찾아 `{{BODY}}` 로 바꾸고, 제목·◦ 항목(`(일시)`형/`일시 :`형 자동 판별)·표 줄 모양을 견본으로 저장
  - 매번 바뀌는 바깥 글자(제목·보고일·담당자 …)는 선택한 것만 입력 칸이 됨
  - 표는 줄 모양별(처음/중간/끝 줄, 합친 칸 포함)로 견본을 따로 저장 → 병합된 표도 모양 그대로
- 주간계획·표 양식처럼 구조가 특별한 양식: `weekly.py` 의 `register_*`/`*Form` 과 같은 방식으로 종류(kind)를 하나 추가
  (`registry.KINDS` 에 등록). form.json 의 `kind` 로 구분합니다.

**개인정보.** 샘플의 이름·전화번호·행사 내용은 양식에 남지 않습니다 (입력 칸 `{{키}}` 로 대체, 본문은 견본만 보관,
미리보기·쓰지 않는 그림은 비움). 담당자 정보는 `%APPDATA%\HwpFormGenerator\profile.json` 에만 저장됩니다.

## 한글 연결 (COM)

- Windows + 한글(2018 이상) + `pip install pywin32` (exe 에는 포함). 한글이 켜져 있으면 실행 중인 한글에 붙고, 없으면 새로 띄웁니다.
- **[한글에 넣기]** = 열린 문서 커서 위치에 hwpx 를 서식째 끼워 넣기(`HwpCtrl.Insert`). 안 되면 **[새 문서로]**.
- 한글이 `접근을 허용하시겠습니까` 창을 띄우면 **모두 허용**. 창이 매번 뜨는 게 싫으면 한컴 개발자 자료실의
  `FilePathCheckerModuleExample.dll` 을 받아 레지스트리
  `HKCU\SOFTWARE\HNC\HwpAutomation\Modules` 에 `FilePathCheckerModuleExample` = DLL 경로 (문자열 값) 로 등록하세요.
- 한글에 연결 못 하는 환경에서는 hwpx 파일을 만들어 연결된 프로그램(한글)으로 엽니다.

## 만들기 / 시험

```
python app.py                                   # 화면
python -m pytest tests --ignore=tests/test_gui.py
xvfb-run -a python3 -m pytest tests/test_gui.py   # 리눅스에서 화면 시험(가짜 한글)

python tools/build_forms.py 학술대회.hwpx 타운홀.hwpx 주간업무계획.hwpx 주요일정.hwpx   # 기본 양식 다시 만들기
```

## 아직 확인 못 한 것 (정직하게)

- 개발 환경(리눅스)에는 한글이 없어 **실제 한글에서 열어 본 것은 아닙니다.** 만든 파일은 다시 읽어 구조를 검사했습니다
  (서식 번호가 header.xml 에 있는지, 표 칸 주소 겹침·rowCnt, 자리표시 잔존, id 중복). 줄 배치 캐시(linesegarray)는 지워 한글이 열 때 다시 계산합니다.
  **처음 한 번은 한글에서 열어 모양을 눈으로 확인**해 주세요. 어긋나는 곳은 알려 주시면 견본 규칙을 고칩니다.
- 한글 COM(`bridge.py`) 도 실제 한글 없이 짠 것입니다. `Insert(…, "HWPX")` 가 한글 버전에 따라 안 될 수 있어 `""`(자동)·새 문서 열기로 대체합니다.
- 한 칸 안의 부분 굵게·밑줄(예: 표 안 `[기조강연]` 만 굵게)은 칸 단위 글자 모양 하나로 찍습니다.
- 주간 주요일정: 일정이 날짜당 기본 3줄 미만이면 3줄로 채우고(기본), 넘치면 줄이 늘어납니다. 노란 강조 칸 모양은 샘플의 월요일 첫 줄에서 가져옵니다.

## 화면 디자인

Linear(인디고→보라 그라데이션)·Notion(차분한 회색 글자, 흰 카드) 느낌에 윈도우 11 유리 질감을 더했습니다: 창 살짝 반투명(알파 0.97),
둥근 모서리 단추(마우스 올림·눌림), 같은 굵기의 선 아이콘(`assets/icons`, `python tools/make_icons.py` 로 다시 그림),
글꼴은 노토 산스(SIL OFL, `assets/fonts`)를 프로그램 안에서만 등록해 사용(없으면 맑은 고딕). 진짜 아크릴 흐림(blur)은 tkinter 로는 못 내서
윈도우 11 의 둥근 창 모서리·제목줄 색만 적용했습니다.

## 예전 형식(.hwp) 파일로 양식 추가

양식 추가는 .hwpx 로 읽습니다. .hwp 는 위젯 `양식 추가` 에서 고르면 **열려 있는 한글이 직접 .hwpx 로 바꿔서** 등록합니다
(한글이 켜져 있어야 함). 한글이 없으면 한글에서 `다른 이름으로 저장 → HWPX` 로 저장한 파일을 쓰세요.
명령줄: `python app.py convert --src 옛양식.hwp --out 새양식.hwpx`.

## 새 양식을 코드로 넣을 때 (`tools/build_forms.py`)

`register_report(sample, out_dir, id, name, audience, fields, slice_=(a,b), drop=[..], section_index=n,
allow_no_body=True, blank_tables={문단:남길줄수}, fix=함수)` — 여러 쪽짜리 문서에서 한 쪽만 잘라 양식으로, 표지처럼 본문 없는 틀만,
표 머리만 남기고 나머지 칸 비우기, 하위 단계(◦ ▸ -) 서식 자동 추출을 지원합니다.
