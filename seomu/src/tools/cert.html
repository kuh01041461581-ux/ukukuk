설정

부서명 기본값, 출력 파일 정보, 인식 방식을 지정합니다.

각 PDF의 소속·부서·기관명을 문서에서 자동으로 인식합니다. 인식 실패 건에만 이 값이 대신 채워집니다.

대부분의 이수증·수료증 PDF에 적합합니다. 완전 무료입니다.

OCR로 잘 안 읽히는 문서를 Gemini로 다시 읽어 정확도를 높입니다.

이 브라우저에만 API 키 저장 (공용 PC에서는 권장하지 않음)

API 키는 이 페이지를 벗어나 저장되지 않으며, 인식이 어려운 문서의 이미지만 Google AI(Gemini) API로 직접 전송됩니다. 키는 Google AI Studio에서 무료로 발급받을 수 있습니다.

서식 관리

엑셀 다운로드에 사용할 서식을 관리합니다. 사용자 서식은 열 제목을 인식해 매칭되는 항목만 채웁니다.

도움말

처음 사용하시는 분들을 위한 간단한 안내입니다.

1️⃣PDF를 올리고 추출 시작을 누르면 자동으로 이름·부서·직급·과정명·이수일을 읽습니다.
2️⃣확인 필요로 표시된 행을 클릭하면 오른쪽에 원본 PDF와 입력값이 나란히 열립니다. 입력창을 클릭하면 PDF의 해당 위치가 노란색으로 표시됩니다 (텍스트 PDF 기준).
3️⃣AI 보정을 켜두면 AI로 다시 인식 버튼으로 제안값과 이유를 보고 적용 여부를 선택할 수 있습니다.
4️⃣수정은 자동 저장되며, Ctrl+Z / Ctrl+Y로 되돌리거나 다시 적용할 수 있습니다.
5️⃣완료되면 엑셀 다운로드로 결과를 저장하세요.
