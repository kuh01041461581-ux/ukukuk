# DeskCalendar

바탕화면 위젯형 달력 + 할 일 / 메모. 디자인: Notion · Linear · Windows 11 풍. PC(Windows)와 안드로이드 폰이 인터넷으로 동기화됩니다.

## 내려받기 (Releases)
**정식 버전**: 저장소 오른쪽 **Releases → 최신(Latest) 버전**의 `DeskCalendar.exe`, `DeskCalendar.apk`. 아래 "최신 빌드"는 개발 중 자동으로 갱신되는 시험용입니다.

저장소 오른쪽 **Releases**
- **DeskCalendar 최신 빌드** → `DeskCalendar.exe` (Windows, 설치 필요 없음)
- **DeskCalendar 안드로이드 최신 빌드 (APK)** → `DeskCalendar.apk` (폰에서 받아 설치 · "출처를 알 수 없는 앱" 허용 필요)

## PC 사용법
- **달력 모양(기본: 유리)**: 바탕화면 그림이 흐릿하게 비치는 반투명 달력. 한 칸마다 날짜·**음력**·절기·공휴일과 `1. 2. 3.` 번호가 붙은 일정이 **줄바꿈으로 전부** 보이고, 완료한 일정은 취소선, 주말은 따뜻한 색, 오늘은 밝은 테두리, 왼쪽에 주 번호. 위쪽 날짜 줄을 끌면 창 이동, `‹ ›`·마우스 휠은 한 주씩, 왼쪽 아래 월 이름은 다음 달로. 설정(`Aa 화면 설정` → 달력 모양)에서 유리/카드, 보이는 주 수(4~6), 유리 색·진하기를 바꿉니다.
- **평소**: 달력만 바탕화면에 떠 있습니다. **날짜 클릭** → 입력 패널이 열리고, 같은 날짜를 다시 누르거나 ✕/Esc 로 닫습니다.
- **기간 일정**: 시작일 → 종료일로 **끌어서** 선택한 뒤 입력. 달력에 이어진 막대로 보입니다.
- **일정 옮기기**: 달력의 일정 칩을 **끌어서** 다른 날짜에 놓기. 더블클릭하면 날짜·시간·기간·반복·메모를 고치는 창.
- **반복 일정**: 수정 창에서 매일/평일/매주/매월/매년 (완료 표시는 날짜별로 따로).
- **탭**: 일정 · 예정(오늘부터 2주 + 지난 미완료) · 보관함 · 검색(Ctrl+F)
- **알림**: 시간이 있는 일정을 미리 알려 주는 카드(5~60분 전 선택) + 아침 요약. `Aa 화면 설정`에서 조절.
- **달력 글자 크기**: 위쪽 `달력 글자 －/＋` 또는 **Ctrl+마우스 휠** → 달력 칸 안 글자만 커지고 줄어듭니다(팝업·입력창은 그대로).
- **항상 뒤에**: 위젯을 클릭해 써도 다른 창 위로 올라오지 않고 계속 뒤에 머뭅니다(Ctrl+Alt+Space 로 불러냈을 때만 앞으로). 창은 화면 밖으로 나가지 않습니다.
- **창 크기**: 가장자리·모서리를 끌면 양방향 화살표로 크기 조절, 날짜 칸도 같이 늘어납니다.
- **화면 설정(Aa)**: 글자 크기·글꼴·글자색·테마 5종·강조색·중요도 색·투명도
- **빠른 입력**: Ctrl+Alt+Space → 오늘 날짜 입력창. `14:30 팀 회의` 처럼 쓰면 시간 태그로 저장
- **공문 PDF**: `공문 PDF` 버튼, 또는 **PDF 파일을 exe 아이콘 위로 끌어 놓기**. 날짜·시간·기한·기간을 찾아 목록으로 보여 주고(이미 있는 항목은 체크 해제 + "이미 있음" 표시), 체크한 것만 추가. **감사·의회·훈련·연수 같은 기간 행사만 여러 날 막대**로 넣고, 그 밖의 "~까지" 기간(제출·조사 등)은 **마감일 하루에** 표시합니다(행마다 `기간` 체크로 바꿀 수 있음). 일정에서 원본 PDF 다시 열기 가능.
- **백업 / 복원 / 내보내기** (⚙ 메뉴): 백업 파일 저장·복원, `.ics`(구글 캘린더 등) 내보내기. 하루 한 번 `%APPDATA%\DeskCalendar\backups` 에 자동 백업(14일).
- **공휴일(공공데이터 API)**: `Aa 화면 설정` → 공휴일에 공공데이터포털 서비스키를 넣으면 임시공휴일·선거일·대체공휴일까지 정확히 받아 반영합니다(30일마다 갱신, 실패하면 내장 규칙). 키는 이 PC에만 저장됩니다.
- **공휴일(내장 규칙)**: 설·추석·부처님오신날·대체공휴일 자동 계산 (2024~2030). 임시공휴일은 알려진 것만 포함.
- 데이터: `%APPDATA%\DeskCalendar\data.json`

## 폰 연결 (어디서나 동기화)
일정은 **AES-256으로 암호화**되어 내 **GitHub 비공개 저장소**를 거쳐 PC와 폰이 주고받습니다. 암호 키는 QR 로만 전달되며 GitHub 에는 올라가지 않습니다. 같은 와이파이일 필요가 없습니다.
1. GitHub 에서 **Private 저장소**를 하나 만듭니다 (예: `deskcalendar-data`, README 추가).
2. GitHub → Settings → Developer settings → **Fine-grained tokens** 에서 토큰 생성: Repository access = 위 저장소 1개만, Permissions → **Contents: Read and write**.
3. PC 앱 ⚙ → **휴대폰 연결** 에 `내아이디/저장소`와 토큰을 입력 → 연결하기.
4. 폰 앱 → **연결** 탭 → **QR 스캔해서 연결**.
이후 일정 변경은 자동으로 동기화(변경 후 몇 초, 앱 실행 중 5분마다, 폰은 앱을 열 때). 두 기기에서 동시에 고쳐도 항목마다 나중에 수정한 쪽이 이깁니다.

## 폰 앱 (안드로이드)
달력 · 예정 · 보관함 · 검색 · 반복/기간/시간/중요도 · 일정 알림(폰에서 직접 예약, 인터넷 없이도 울림) · 아침 요약.
알림 시각은 배터리 절약(Doze) 때문에 몇 분 늦을 수 있습니다.

## 직접 빌드
- PC: Windows 에서 `build.bat` → `dist\DeskCalendar.exe`
- 폰: `cd mobile && flutter build apk --release` (Flutter 3.24.5)
- 둘 다 GitHub Actions 가 push 마다 자동으로 빌드해서 Releases 에 올립니다.

## 정식 버전 올리는 법 (관리자)
GitHub → Actions → **Release (정식 버전)** → Run workflow → 버전 입력(예: 1.0.1) → 실행하면 exe/APK 를 빌드해 새 Release 로 올립니다.
안드로이드 서명 키는 `mobile/android/keystore/` 에 포함된 내부 배포용 키로 고정되어 있어서 새 APK 가 기존 설치본 위에 업데이트로 설치됩니다. (스토어 출시 전에는 별도 키를 만들어 GitHub Secrets 로 옮기세요.)
